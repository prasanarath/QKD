# BB84 Quantum Key Distribution Protocol

## Overview

The BB84 protocol, developed by Charles Bennett and Gilles Brassard in 1984, is the first and most fundamental quantum key distribution (QKD) protocol. It demonstrates how quantum mechanics can be used to create unconditionally secure cryptographic keys.

## Key Principles

### 1. Quantum States Cannot Be Cloned
- **No-Cloning Theorem**: It's impossible to create a perfect copy of an unknown quantum state
- This prevents Eve from intercepting and copying photons without detection

### 2. Measurement Disturbs Quantum States
- Measuring a quantum state in the wrong basis changes the state
- This disturbance can be detected by Alice and Bob

### 3. Uncertainty Principle
- Certain properties of quantum particles cannot be simultaneously known
- Eve cannot extract complete information without introducing errors

## Protocol Steps

### Step 1: Key Encoding by Alice
Alice prepares a sequence of photons, each encoding one bit of information:

| Bit | + Basis | × Basis |
|-----|---------|---------|
| 0   | → (Horizontal) | ↗ (Diagonal) |
| 1   | ↑ (Vertical) | ↘ (Anti-diagonal) |

**Process:**
1. Randomly select a bit (0 or 1)
2. Randomly select a basis (+ or ×)
3. Prepare photon in corresponding polarization state

### Step 2: Transmission to Bob
- Alice sends polarized photons through quantum channel
- Quantum channel can be optical fiber or free space
- Each photon carries one bit of information

**Security Features:**
- No-cloning theorem prevents copying
- Measurement disturbance reveals eavesdropping
- Uncertainty principle limits information extraction

### Step 3: Measurement by Bob
Bob receives photons and measures each one:

**Measurement Outcomes:**
- **Basis Match**: Perfect correlation (100% accuracy)
- **Basis Mismatch**: Random result (50% accuracy)

**Example:**
- Alice sends: 1 in + basis (↑)
- Bob measures: + basis → Result: 1 ✓
- Bob measures: × basis → Random result: 0 or 1

### Step 4: Basis Comparison
After transmission, Alice and Bob publicly compare basis choices:

**Process:**
1. Public communication of basis choices
2. Identify photons with matching bases
3. Form raw key from matching measurements

**Key Insight:**
- Basis information is public and not secret
- Only bit values remain private
- Raw key length is typically 25-50% of transmitted bits

### Step 5: Eavesdropper Detection
Alice and Bob detect Eve through error rate analysis:

**Detection Methods:**
1. **Error Rate Analysis**: Compare subset of raw key
2. **Privacy Amplification**: Apply cryptographic techniques

**Eve's Impact:**
- **Without Eve**: Error rate ~0%
- **With Eve**: Error rate increases to ~25%

**Security Thresholds:**
- < 2%: Secure (proceed with key generation)
- 2% - 11%: Suspicious (apply privacy amplification)
- > 11%: Insecure (abort protocol)

### Step 6: Final Secret Key
After successful eavesdropper detection:

**Key Distillation Process:**
1. **Error Correction**: Fix remaining bit errors
2. **Privacy Amplification**: Eliminate Eve's information
3. **Final Key Generation**: Create secure secret key

**Final Key Properties:**
- Information-theoretic security
- Optimal length for security
- Perfect randomness
- Unconditionally secure

## Security Guarantees

### Unconditional Security
- Secure against any computational attack
- Security based on laws of physics
- Future-proof against quantum computers

### Forward Secrecy
- Compromised keys don't affect past communications
- Each session generates new keys

### Eavesdropper Detection
- Any interception attempt is detected with high probability
- Protocol can be aborted if security is compromised

## Mathematical Foundation

### Quantum States
- **+ Basis**: |0⟩ = |→⟩, |1⟩ = |↑⟩
- **× Basis**: |0⟩ = |↗⟩, |1⟩ = |↘⟩

### Measurement Operators
- **+ Basis**: σz measurements
- **× Basis**: σx measurements

### Key Rate
- Raw key rate: R = 1/2 (50% basis matching)
- Final key rate: R_final = R × (1 - h(e))
- Where h(e) is binary entropy function

## Practical Considerations

### Channel Loss
- Photon loss reduces key rate
- Error correction compensates for losses
- Maximum distance limited by channel quality

### Detector Efficiency
- Real detectors have < 100% efficiency
- Dark counts create errors
- Dead time reduces key rate

### Environmental Factors
- Temperature affects detector performance
- Vibration can misalign optics
- Background light creates noise

## Conclusion

The BB84 protocol represents a paradigm shift in cryptography, moving from computational security to information-theoretic security. While practical implementations face technical challenges, the theoretical foundation provides a roadmap for future quantum-secure communications.

The protocol's elegance lies in its simplicity - it uses only basic quantum mechanics principles to achieve what classical cryptography cannot: unconditional security based on the laws of nature rather than computational assumptions.
